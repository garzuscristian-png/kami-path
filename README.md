# Kami Path

Crea un mapa para un videojuego 3D Survival que se desenvuelve en Japón, cada punto del mapa podrá ser seleccionado, pero por el momento solo desarrrolla la logica mediante un sistema de nodos conectados para gestionar el progreso del jugador. permitiendo desbloquear nuevas zonas tras completar objetivos específicos en cada nodo. También incluye un árbol de habilidades vinculado a la exploración de dichas áreas. Cada nodo abrirá un escenario 3D para farmear, estoy viendo si los escenarios serán procedurales pero aún lo tengo claro.
